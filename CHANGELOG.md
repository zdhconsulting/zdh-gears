# Changelog

## 1.5.3

Corrects discrepancies found while verifying the released and installed 1.5.2 package.

- Auto Selection prefixes now produce the same route as the task alone. Mode descriptions and negations no longer activate Boost. Explicit `-Mode auto|boost|save-tokens` applies for one invocation.
- Save Tokens now uses standard service across a task-aware matrix: Spark low for mechanical work, Luna low for positively identified bounded implementation, GPT-5.6 Sol low for explicitly bounded debugging, and Astra high for architecture, security, destructive, production, migration, or broad work. Unknown tasks retain balanced Astra low and substantive reviews retain Astra high. Auto Selection stays unchanged.
- Boost now requests fast service while preserving Astra ultra. Service speed does not downshift its reasoning or model.
- Launcher prompts travel through stdin. Receipts separate selected/requested settings, process exit and unverified backend configuration. Missing commands do not claim arguments were passed. Receipts use unique files and honor PowerShell's current directory.
- The native plugin installer uses the existing `codex-gears@zdh-gears` identity and no longer overwrites shared scripts, configuration or caches itself.
- Doctor failures return nonzero with JSON output. CI checks routing, actual launcher arguments with a fixture, receipts, package metadata, installation failures and valid exact-ID usage records on Windows and Linux.
- Skill, README, and pack contract now agree on all saver profiles and document a concise workflow that preserves necessary verification. The existing logo uses supported `interface.composerIcon` and `interface.logo` fields.

Backend-applied model settings, another account's model availability, automatic conversation interception, account cost, token percentages, and measured token savings are not established by these checks. The model IDs and low effort were validated only against one local advertised `models_cache`. No capacity-aware chooser or automatic fallback retry is included in this patch.
